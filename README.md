# تمرین میانه

یک درس خواندنی و یک سؤال سه‌گزینه‌ای دربارهٔ میانهٔ پنج اندازه‌گیری. متن و داده‌های تمرین برای همین نمونه نوشته شده‌اند. اگر گزینهٔ نادرست را انتخاب کنید، بازخورد توضیح می‌دهد چطور از آن اشتباه به جواب برسید.

## شروع سریع

از پوشهٔ مخزن، با Python 3.8 یا جدیدتر و یک پایانهٔ UTF-8 اجرا کنید. برنامه فقط از کتابخانهٔ استاندارد پایتون استفاده می‌کند و آفلاین اجرا می‌شود.

```sh
python3 tutor.py
```

پس از خواندن درس، شمارهٔ یکی از سه گزینه را وارد کنید. برنامه رقم‌های فارسی، عربی و لاتین را می‌پذیرد. برای دیدن یک اجرای کامل با پاسخ از پیش انتخاب‌شده، فرمان زیر را اجرا کنید.

```sh
python3 tutor.py --answer ۲
```

دو خط آخر خروجی چنین خواهد بود.

```text
پاسخ درست است.
از کم به زیاد، زمان‌ها ۴، ۵، ۶، ۹ و ۲۱ دقیقه‌اند. عدد سوم ۶ است و دو اندازه‌گیری در هر طرف آن قرار دارند.
```

با `--answer ۱` دلیل اشتباه گرفتن عدد وسط فهرست اولیه با میانه را می‌بینید. پاسخ به هر گزینهٔ معتبر، اجرای تمرین را با کد خروج صفر تمام می‌کند. در اجرای تعاملی، شمارهٔ نامعتبر دوباره پرسیده می‌شود. در اجرای فرمانی، شمارهٔ نامعتبر کد خروج ۲ می‌دهد.

## دامنهٔ نمونه و آزمون

متن درس، سؤال، گزینه‌ها و بازخورد هر پاسخ در `lesson.json` قرار دارند. برنامه همین تمرین متنی را در حافظه اجرا می‌کند و پاسخ کاربر را روی دیسک ذخیره نمی‌کند.

```sh
python3 -m unittest discover -s tests -v
```

آزمون‌ها فرمان واقعی را از یک پوشهٔ موقت اجرا می‌کنند و پاسخ درست، بازخورد هر دو گزینهٔ دیگر، قالب رقم‌ها، ورودی نامعتبر و پایان ورودی را می‌سنجند.
